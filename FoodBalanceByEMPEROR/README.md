# FoodBalanceByEMPEROR

Баланс еды для The Long Dark. Ползунки в настройках: сколько еды разных модов лежит на картах и в контейнерах.

Food balance for The Long Dark. Settings sliders: how much food of each food mod spawns on maps and in containers.

Версия / Version: **1.0.1**. Игра 2.60, MelonLoader 0.7.3 / Game 2.60, MelonLoader 0.7.3.

## Скачать и установить / Download and install

**Проще всего:** лаунчер [TLDModsLauncher.exe](https://github.com/Saderto/TLDCoop/releases/latest/download/TLDModsLauncher.exe). Отметьте **Баланс еды** и нажмите «Установить / обновить»: он сам
поставит MelonLoader, нужные библиотеки и будет обновлять мод.

**Вручную:** скачайте архив [FoodBalanceByEMPEROR.zip](https://github.com/Saderto/TLDCoop/releases/download/v1.0/FoodBalanceByEMPEROR.zip) и распакуйте его в папку игры `TheLongDark` с заменой файлов.

**Easiest:** the launcher [TLDModsLauncher.exe](https://github.com/Saderto/TLDCoop/releases/latest/download/TLDModsLauncher.exe). Tick **Food balance** and press "Install / update": it sets up
MelonLoader and the libraries needed, and keeps the mod updated.

**By hand:** download [FoodBalanceByEMPEROR.zip](https://github.com/Saderto/TLDCoop/releases/download/v1.0/FoodBalanceByEMPEROR.zip) and unpack it into the game folder `TheLongDark`, replacing files.

Works with [CoopByEMPEROR](../CoopByEMPEROR): both players must run the same mods and versions.
